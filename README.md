# Rotation

This is a Luanti mod to set the rotation of the player.

## Commands

* `/set_h`
* `/set_v`
* `/set_r`

 You can check that by pressing the F10 key and typing: "/help".

### `set_h`

* Usage: `/set_h <degrees>`
* Description: Set the horizontal rotation of the player
* Parameters:
* `<degrees>`: The degrees

### `set_v`

* Usage: `/set_v <degrees>`
* Description: Set the vertical rotation of the player
* Parameters:
* `<degrees>`: The degrees

### `set_r`

* Usage: `/set_r <degrees>`
* Description: Set the rotation of the player
* Parameters:
* `<degrees>`: The degrees
